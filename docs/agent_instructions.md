# Maintenance workflow

Read applicable repository and parent guidance. Preserve user changes and use the shared GitVault lock/migration guard for canonical repository writes. This is private research; keep sources and output in the private origin.

For numerical changes, confirm conventions and add meaningful analytical regressions. For experiment changes, update the methods/statistics guides and manuscript together. Keep scripts thin and use real computations/files in tests.

For manuscript changes, verify claims against retained evidence or primary scholarship, validate references/figures and render through the pinned template. Leave unspecified author/publication declarations unknown. Read [rendering](rendering_pipeline.md) and [outputs](output_conventions.md) for the build order.

Before completion, run tests, reproduction, manuscript/documentation validation, relevant package/script checks and template rendering. Inspect figures and final editions, refresh provenance, review the diff, and verify any requested push against the remote commit. Report actual check results and limitations. Sending summaries requires user authorization.
