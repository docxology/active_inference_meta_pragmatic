# Rendering with docxology/template

The publication PDF and HTML editions use the actual combined renderers from [docxology/template](https://github.com/docxology/template), pinned by `template.lock.json`. The adapter checks the checkout's origin, exact commit and tracked cleanliness. It invokes that checkout's Python environment without copying or modifying its rendering infrastructure. The research package remains independently installable.

Set up a clean template checkout at the pinned revision and install its dependencies following its README. Pandoc, XeLaTeX and BibTeX must be on PATH. TeX Live/TinyTeX needs the packages used by the template and this manuscript; installing a TeX distribution is separate from installing Python dependencies.

```bash
export TEMPLATE_ROOT=/path/to/template
uv run python scripts/07_analysis_pipeline.py
uv run python scripts/08_render_with_template.py --template-root "$TEMPLATE_ROOT"
uv run python scripts/09_validate_documentation.py
```

Pass `--template-python /path/to/python` when the template environment is elsewhere. Use `--output-dir` to retain editions in a different directory. The default publication editions are `results/template/pdf/active_inference_meta_pragmatic_combined.pdf` and `results/template/web/index.html`, with sibling figure assets, composition evidence and `renderer_manifest.json`.

The upstream renderer runs in the active project checkout's ignored `output/pdf`, `output/web` and `output/figures` directories. Only successful editions are copied into `results/template/`; compiler logs, AUX/BibTeX sidecars and intermediate LaTeX stay under ignored `output/`. Private sources are never copied into the public template repository.

The template HTML uses its pinned MathJax CDN loader and requires network access for mathematical typesetting. The PDF is self-contained. `results/manuscript.html` is a separate local MathML preview generated by the standalone research workflow; it is useful offline and is not described as a template-rendered edition.

The manuscript's `preamble.md` sets 0.35-inch page margins (8.89 mm). The geometry options `includefoot,footskip=0.18in` keep the page number within that page boundary while reserving footer space below the text. The template recognizes the user-supplied geometry package, so its source remains unmodified. Red publication links and the two-level table of contents are also set in the manuscript preamble. Inspect page breaks, figure captions and long notation tables after changing geometry; HTML does not inherit print margins. See [research integrity](research_integrity.md) for the publication verification requirements.

The HTML input is a recorded format projection under ignored `output/manuscript/`: citations become Pandoc citations; references and displayed equation tags use the actual compiled PDF AUX numbers; figures become semantic Markdown images. Authored source is preserved. The renderer receipt records the projection algorithm, AUX digest, reference mapping and consumed hydrated-source hashes. Both editions therefore retain citations, linked references, mathematics and research figures.

After changing scientific sources: reproduce the research, render with the template, inspect the latest PDF/HTML and figures, then refresh the research manifest. The renderer receipt records the actual template revision, tool versions, consumed manuscript hashes and publication artifact hashes. Changing the template pin requires a reviewed rerender and updated receipt.
