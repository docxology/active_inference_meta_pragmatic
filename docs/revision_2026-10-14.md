# Version 1.2: executable models and a revised manuscript

The initial validation record below describes the first GNN revision. The subsequent statistical/scholarship expansion is documented in [the expansion record](expansion_2026-10-14.md), which supersedes its manuscript, figure, test and digest counts.

Base commit: `c59dd008b5e7b6fd9faec1e3d522889fc143de74`. The revision is on `codex/gnn-manuscript-revision`. The earlier canonical scientific-review checkout and its unfinished evidence are preserved.

## Implementation and scientific scope

The actual upstream `MarkdownGNNParser` is imported from the Generalized Notation Notation checkout, pinned at `46459949944e3217f8a6a804d4ff8c52829ef275`. Authored binary-sensor and stay-switch agent specifications define the categorical models. Numerical revisions, the experiment, random-model identity checks and reliability sweep pass through materialized GNN source and the strict local profile. The current experiment retains 57 selected sensor realizations; historical intermediate specification bytes are preserved separately.

The supported runtime is the local exact categorical engine. The adapter admits one factor and modality; it does not claim upstream native-backend, continuous, hierarchical or multi-agent support. Python support now begins at 3.11, matching upstream GNN's declared requirement. The package is version 1.2.0.

The retained experiment still has 30 independent seeds, 400 held-out trials per seed and separate labeled training. Its original five conditions reproduce the earlier reported estimates. Fixed four- and five-observation comparators add resource context, producing seven conditions and 210 seed-by-condition rows. These additions are descriptive; they do not change the three-comparison Holm family. Calibration plots pool trials descriptively, with ten fixed probability bins and no inferential intervals.

## Observed verification

- All 565 tests pass on actual external Python 3.11.15, 3.12.13 and 3.13.14 environments. Both virtual-environment and base-interpreter paths resolve on GitVault.
- Unit/integration branch coverage is 93.15%. Appending actual template CLI and worker execution gives 94.92%, above the 90% gate and slightly below the 95% target. No threshold was changed.
- The upstream syntax validator accepts both authored GNN models and rejects a malformed control. Local tests reject malformed dimensions, unsupported profiles, wrong dependencies, impossible evidence, invalid probabilities and inappropriate dynamic sensor models. Tests also observe actual belief, transition and policy effects.
- The default pipeline completes. Across 50 imported random categorical models and 200 two-step policy checks, maximum EFE and VFE identity errors are approximately 4.44e-16 and 8.88e-16.
- Manuscript validation observes 13 sections, 25 labels, 27 cited/bibliographic records and four numbered figures.
- Browser inspection observes five loaded images with descriptions, 27 reference entries, 63 typeset expressions, no MathJax errors and no broken internal anchors. A 390-pixel viewport has no horizontal document overflow; desktop inspection also passes.
- Wheel and source distribution build. The wheel installs in a separate external environment and imports from site-packages while running outside the checkout. Its installed GNN models produce the expected posterior and two-action demonstration model.
- Focused Ruff diagnostics pass. The programming-rule checker reports no violations in the new GNN, visualization and test files. This is not a claim of a repository-wide strict type-checker run.
