# Version 1.0.0: publication and reproducibility

The public [GitHub repository](https://github.com/docxology/active_inference_meta_pragmatic) contains the maintained source on `main`. Version 1.0.0 is available as a [GitHub release](https://github.com/docxology/active_inference_meta_pragmatic/releases/tag/v1.0.0) and [Zenodo preprint](https://zenodo.org/records/23397453), DOI [10.5281/zenodo.23397453](https://doi.org/10.5281/zenodo.23397453). The annotated tag selects commit `eadfa2f030ea068df7ebdddc341829f20b85c713`.

## Scope and authorship

The work combines a conceptual framework, executable GNN models, exact categorical calculations and synthetic studies. It is a preprint, without claimed peer review, independent replication or biological validation. Author: Daniel Ari Friedman, Active Inference Institute and FractiAI; ORCID 0000-0001-6232-9096. Files use Apache-2.0. [Research integrity](research_integrity.md) documents assistance, responsibility and unspecified declarations.
