# Inquiry roles and scientific figure encodings

Q1–Q4 identify four overlapping responsibilities in the proposed conceptual map. They are not sequential stages, biological faculties or evidence of autonomous model revision.

## Definitions that travel with the figure

| Label | Full role name | Operational question |
|---|---|---|
| Q1 | Infer and act | What follows from the observations and declared model? |
| Q2 | Contextualize evidence | Which source reliability and context condition that inference? |
| Q3 | Monitor inquiry | Should further observations be acquired under the resource budget? |
| Q4 | Evaluate and revise | Which assumptions should be challenged, and what justifies adoption of a revision? |

`visualization.inquiry_roles` owns the shared names, operational descriptions and conceptual colors. The cover, quadrant orientation and revision map reuse these declarations. Each cover card contains both the full name and a concrete description. The cover also spells out Generalized Notation Notation and expected free energy, and separates conceptual responsibilities from the retained sensor estimates and exact action probabilities.

The Q-coded experimental conditions are narrower operational examples: a fixed model, true source metadata, adaptive acquisition and fitted reliability. Their outcomes do not validate the complete philosophical roles. Captions make this distinction explicit.

## Visual encodings

| Figure | Encoding |
|---|---|
| Scientific graphical abstract | Four self-contained role definitions, explicit abbreviations and two separate evidence panels |
| Quadrant orientation | Full shared role names, concrete operations, conceptual axes and separate failure cases |
| Executed model diagrams | Sensor reliability shown as percentage correct; evidence grouping and action-mode labels clarified |
| Sensor comparison | Consistent conceptual/strategy colors and a role-plus-mechanism key; seed units and resources remain visible |
| Prediction and resources | Aligned strategy rows, explicit fitted-model label, and calibration line styles supplementing color |
| Action outcomes | Strategy-specific symbols, capped seed intervals and displaced open diamonds for exact expectations |
| World–model mismatch | Favorable score directions and distinct calibration symbols/line styles |
| GNN tensor atlas | Cell boundaries, explicit hidden-state and before/after-action axes, all values including zeros retained |
| Exact EFE decomposition | Full objective name, information/ambiguity identity and separate risk/ambiguity decomposition |
| Paired contrasts | Named, lettered metric panels with opposite favorable directions for accuracy and losses |
| Stopping sensitivity | Capped intervals only at evaluated thresholds; connecting lines explicitly guide the eye |
| Policy landscape | Equal-EFE/equal-probability contour, signed score direction and retained-design marker |
| Revision workflow | Shared full role names above specification, execution, evaluation and justified revision |

All twelve numbered captions explain what the reader compares, the encodings, units, uncertainty and limits. Seed intervals, exact evaluations and conceptual diagrams remain distinct. See [statistics](statistics.md), [GNN methods](gnn_models.md) and [figure readability](figure_readability.md).

Shared definitions live in `visualization.inquiry_roles`. Run the research pipeline and pinned-template renderer, then inspect the actual graphics and publication pages. Tests distinguish sampled from exact probabilities, enforce the source typography floor and exercise real exports.
